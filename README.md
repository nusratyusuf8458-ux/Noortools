# NoorTools — Phase 1 + Phase 2 foundation

Privacy-first Islamic companion foundation built for `nusratyusuf8458-ux/Noortools`.

## Phase 1
- Responsive premium light/dark UI with accessible focus states and mobile-safe areas
- Explicit device/manual location selection; no silent default city or coordinate
- Coordinate-derived IANA timezone and timezone-safe prayer dates/times
- Offline astronomical prayer calculation for Fajr, Sunrise, Dhuhr, Asr, Maghrib and Isha
- Current/next prayer, countdown, high-latitude fallback conventions and Qibla sensor handling
- Genuine Salah/Tasbih activity and versioned defensive local storage
- Safe local-data export/import with validation and confirmation
- Android-facing defensive browser/PWA behaviors

## Phase 2 content foundation
- Additive verified-library surface that does not rewrite Phase-1 navigation or activity storage
- Reusable `ReligiousContentItem` schema with Arabic, translation, transliteration, source/reference, collection, edition, version, license and verification metadata
- Explicit verification states: `verified`, `needs_review`, `unavailable`
- Separate scholar-review metadata and review-decision workflow; the code never claims a scholar reviewed content unless a named review decision is recorded
- Quran architecture for 114 surahs, ayah reader, Juz, pages, reading settings, bookmarks, last-read, progress, search, translation and audio provider interfaces
- Strict Tanzil Uthmani v1.1 source acquisition/import validator; the canonical Arabic source is treated as immutable input
- Local versioned bookmarks, Quran reading positions and count-based completion state with no seeded/fake activity
- Source-aware empty states for 99 Names, Duas, Morning & Evening Azkar and Hadith rather than fabricated religious text
- Requested category taxonomies for Duas, Azkar, Hadith and 99 Names without source text
- Global search that indexes only currently available verified content
- Modular translation and audio provider contracts with unavailable providers until licensed/authorized sources are connected

## Phase 2.4 experience layer
- Premium Quran reading controls and navigation for Surah, Juz and page positions
- Explicit user-driven Quran reading activity, last-read continuation, history and progress; rendering alone never marks an ayah read
- Robust local bookmarks/favorites, user notes and permission-aware reminder preferences
- Deterministic Daily Ayah, Dua, Dhikr and Name-of-the-Day presentation from available verified datasets only
- Premium verified-content search with type filters, result counts, empty/no-result states and Unicode/Arabic-safe presentation-only highlighting
- Local-only search history with sanitization, deduplication, bounded retention and clear controls
- Explicit Pickthall translation-unavailable state for the four Phase-2.3 excluded records; no replacement translation is generated
- Responsive RTL-aware UI, keyboard focus states, reduced-motion support and mobile-safe touch targets

## Religious-content policy
No Quran, Hadith, Dua, Azkar, fiqh ruling, fatwa, scholar statement, Prophet/Sahaba story or Seerah statement is generated by NoorTools. Content is not marked verified merely because code passes tests.

## Quran source policy
The planned Quran Arabic source is Tanzil Project Uthmani v1.1. NoorTools treats the downloaded source text as immutable input and records SHA-256 provenance. See `content-source/README.md` and the phase-specific source manifests.

Quran Foundation's Content APIs are recorded as a supported future provider for Quran text, translations, pages, juz, recitations and search. Its current developer terms restrict redistribution of raw API data, so NoorTools does not bundle unauthorized raw API content.

## Android verification limit
Physical Android device/emulator validation is **NOT PHYSICALLY VERIFIED**. The same applies to physical sensors, Android notification delivery, vibration behavior, screen-reader/device-matrix testing, and Android WebView/browser differences. No Play Store readiness claim is made on the basis of browser/CI tests alone.
